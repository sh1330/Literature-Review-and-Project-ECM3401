# Project Deliverables
### 1. Literature Review
- Research established SWE practices, agentic AI, guardrails, and evaluation methods
### 2. Agentic Development Workflow
- A structured process defining AI responsibilities, human oversight, guardrails, testing, and code review.
### 3. Practical Software Application
- An application developed using agentic AI, with clear requirements and acceptance criteria.
### 4. Experimental Methodology
- A documented approach for evaluating agent behaviour, including experimental conditions, tasks, evaluation criteria and data collection.
### 5. Evaluation Results and Analysis
- Measurable findings on functional correctness, process adherence, human intervention and guardrail effectiveness.
### 6. Final Report
- An analysis of the findings for applying established SWE practices to agentic development
