## Problem Statement
With the rise of agentic AI systems, more and more software engineers are utilising their capabilities in almost all aspects of their work such as, performing substantial software development tasks, but traditional software engineering development processes and practices are designed around development being human led. This shift in how software is developed poses uncertainties around the processes and practices that are used when using an AI agent to perform large portions of the implementation.
Currently, it isn’t clear what tasks or decisions can be delegated to an AI agent safely, what should remain human led, what guardrails should be used, and how should the work be reviewed. This is relevant across the software development lifecycle, including requirements engineering, design, implementation, testing and code review. 
This project aims to investigate these open questions by using established software engineering literature to outline practices that more closely align with agentic AI workflows, and then empirically examining how an agentic AI behaves within a controlled development process. By using a practical software project, this will allow different approaches to be evaluated with factors such as autonomy, guardrails and human oversight to be tested.
