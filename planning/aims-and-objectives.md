# Project Aim and Objectives
## Aim
Investigate how established software engineering practices and human oversight can be applied when agentic AI performs a substantial proportion of the software implementation, through the development and empirical evaluation of a structured agent-assisted workflow.

## Objectives
#### 1. Establish a SWE baseline through literature review
- Review established SWE principles and current research into agentic AI, looking at development practices, potential risks, existing approaches to human oversight, and evaluation methods
#### 2. Define a structured development workflow for agentic AI
- Construct an appropriate workflow that will be built using literature that researches the responsibilities of the AI agent and human developer, this will include guardrails, approval stages, testing, and code review.
#### 3. Design and implement a software system using agentic AI
- Select a software application, establish its requirements and acceptance criteria, and implement a demonstrable system using agentic AI within a documented development process.
#### 4. Design and conduct an empirical evaluation of the workflow
- Develop an experimental approach to assess the effectiveness of the proposed workflow, potentially comparing it against a less restricted agentic AI development approach using comparable, if not the same, SWE tasks.
#### 5. Measure and analyse the performance of the agentic development process
- Evaluate the agents performance using defined criteria such as functional correctness, adherence to the development process and guardrails, human intervention required, and the effectiveness of implemented guardrails
#### 6. Evaluate the findings against established software engineering principles
- Analyse the experimental results to identify the strengths, limitations and trade-offs of the proposed approach, and develop recommendations for integrating agentic AI into software engineerng practice.
