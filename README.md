## ECM3401 - Literature Review and Project
Project Supervisor - Prof. Shirley Atkinson

#### Proposed Project title - Applying Established Software Engineering Practices to Agentic AI Development: Autonomy, Guardrails, and Human Oversight


#### Overview
This project aims to investigate how established SWE practices should be applied when agentic AI performs a substantial proportion of software implementation, with a focus on agent autonomy, guardrails, and human oversight throughout the software development lifecycle.
Please find a more detailed problem statement in [Problem Statement](planning/problem-statement.md)
