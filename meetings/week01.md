## Project Focus
The main focus of the project will be:
- How should an established software engineering discipline be applied when an AI agent is doing a substantial share of the implementation?

The project should investigate how traditional software engineering practices interact with the increasing use of agentic AI during software development

The main Software Development Lifecycle areas currently are:
- Requirements engineering
- Analysis and design
- Implementation
- Test-driven development / testing

#### Project supervisor summary of discussions
- Software engineering principles and the role of agentic AI.   How should an established software engineering discipline (requirements engineering, analysis and design, implementation, test-drive development) be applied with an AI agent is doing a substantial share of the implementation.  What are the choices to be made at each part of the Software Development Lifecycle phase and the guardrails to be put into place.
